Guess It 1, prédire le prochain nombre

Go, statistiques

Contexte
Projet Zone01 : prédire une plage pour le prochain nombre d'une série.
Mon rôle
Projet réalisé seul : algorithme et programme complet.
Résultat
80 à 90 % de réussite sur les jeux de données de test, devant les algorithmes de référence (moyenne, médiane, grande plage).
Liens
code sur GitHub
Voir le détail

Le problème

Le programme reçoit des nombres un par un et doit donner une plage pour le suivant. Plus la plage est petite, plus le score est élevé, mais une plage trop petite rate le nombre : il faut trouver le bon compromis.

Choix techniques

Je calcule la médiane de tous les nombres déjà vus, puis le MAD (écart absolu médian) pour fixer la largeur de la plage. Ces deux mesures résistent aux valeurs extrêmes, contrairement à la moyenne.

Ce que j'ai appris

Statistiques appliquées, performance (plus de 10 000 nombres traités) et comparaison de mon algorithme à d'autres lors de l'audit.
